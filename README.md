# musical-lab
Musical related experiments

## Projects

Selected harmonics-related project ideas, organized as one root folder per
project. See [`plans/harmonics-projects-plan.md`](plans/harmonics-projects-plan.md)
for the full selection rationale, tech stack, and build order.

1. [`harmonic-spectrum-explorer/`](harmonic-spectrum-explorer/README.md) — foundational FFT/harmonics analysis and visualization
2. [`guitar-harmonic-fingerboard/`](guitar-harmonic-fingerboard/README.md) — guitar fretboard harmonic visualizer
3. [`harmonic-practice-assistant/`](harmonic-practice-assistant/README.md) — guitar + neuroscience practice feedback tool
4. [`physics-of-music/`](physics-of-music/README.md) — grand educational app integrating the above modules
